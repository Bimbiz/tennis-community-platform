# Mobile Application UI/UX Prototype

## Project
Amateur Tennis Community Platform

## Figma Prototype
[View Interactive Prototype](https://www.figma.com/design/sE4gEJWR9tk9OnSE8iT5mX/ATC-prototype?node-id=0-1&t=FzblQIyH5qE6NiE9-1)

## Description
This prototype demonstrates the main user interfaces and workflows of the Amateur Tennis Community Platform mobile application.

The application allows amateur tennis players to discover tournaments, register for singles and doubles competitions, view their estimated NTRP-inspired skill levels, and track tournament match results.

Match results are submitted by players and approved by tournament organizers before affecting the internal rating.

## Included Screens
1. Login
2. Registration
3. Home
4. Tournaments
5. Tournament Details
6. Match Details (Player)
7. Match Details (Organizer)
8. Rating
9. Player Profile
10. Tournament Participants

## Notes
- The prototype was created using Figma.
- The screens contain demonstration data.
- The numerical internal rating is hidden from players.
- Only approved tournament matches affect player ratings.
- Some interactions are represented as visual concepts and will be implemented during development.
